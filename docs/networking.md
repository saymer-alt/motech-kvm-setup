# Сеть: br0 и отдельный IP Windows

## Требование NET-01
Виртуальная Windows — отдельный узел корпоративной LAN, со своим виртуальным MAC и IP-адресом. Хост МосТех тоже получает отдельный IP. NAT-сеть libvirt (`virbr0`) **не является целевой схемой**. Для администрирования Windows используется LiteManager.

## Что делает исходный `setup-bridge.sh`
1. Проверяет root и работающий NetworkManager.
2. При обнаружении `br0` предлагает удалить и пересоздать мост.
3. Предлагает физический Ethernet.
4. Создаёт профиль NetworkManager для моста `br0` и Ethernet-порта.
5. Отключает старое подключение, активирует мост и ждёт DHCP-адрес.
6. Выводит команды ручного отката.

## Известные риски — прочитать до запуска
- Текущий скрипт **не переносит настройки статического IP, DNS, маршрутов или VLAN** и ожидает DHCP.
- Во время выполнения соединение может оборваться; нельзя считать безопасным запуск через SSH/RDP/удалённую поддержку.
- При частичном сбое возможны конфликтующие/осиротевшие профили `nmcli`; автоматический rollback не гарантирован.
- Повторное создание `br0` потенциально разрушительно, его нельзя выполнять на действующем рабочем месте без плана восстановления.
- Сохраните заранее `nmcli connection show`, `ip address`, `ip route`, сведения о доменной связности и доступ к локальной консоли.

## Диагностика после установки
```bash
nmcli -f GENERAL,IP4 device show
nmcli connection show
ip -br addr
ip -4 route
bridge link
virsh -c qemu:///system domiflist ИМЯ_VM
```

В Windows выполнить `ipconfig /all`, проверить контроллер домена и подключение LiteManager. Ни внутренние IP, ни DNS, ни доменные имена не публиковать в issue.

## Откат
В конце исходного скрипта печатаются команды `nmcli` для удаления моста и подъёма старого профиля, однако это **не транзакционный откат**. Выполнять с локальной консоли; не копировать команды без проверки имен профилей.

## Будущие задачи
Добавить read-only preflight, проверку DHCP/static, backup и подтверждение, отложенный rollback, диагностику и минимизацию простоя. До испытаний новую логику не внедрять в рабочие пять компьютеров.
