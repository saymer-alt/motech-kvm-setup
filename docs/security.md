# Безопасность публикации и эксплуатации

- Исходный `autounattend.xml` содержал **открытый пароль** локального администратора и имя учётной записи. Оригинал исключён из репозитория; пароль следует сменить на затронутых системах.
- Не публиковать в issue, логах, скриншотах и коммитах пароли, токены, внутренние IP, доменные имена, идентификаторы сотрудников и сведения о доступе.
- Исторические скрипты сохранены с минимальной обезличивающей правкой. **Не считать прошедшими полноценный security-audit**, несмотря на положительный опыт эксплуатации.
- `libvirt` + Polkit для всей группы `libvirt` потенциально даёт пользователю широкое управление гипервизором.
- Создание моста может отключить хост от сети. В текущем скрипте нет надёжного автоматического отката.
- Windows 10 требует поддерживаемого порядка обновлений/сопровождения и соблюдения лицензионных правил организации.
- Отсутствие лицензии в этом репозитории **не означает** разрешения свободно перепубликовать материалы работодателя. Правовой статус подлежит уточнению.
- Проверять изменения на отдельной тестовой машине и сохранять действующие конфигурации до проверки.
